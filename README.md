## Задача варианта

Анализ ширины макетов в пикселях. Исходные данные: `[1280, 1920, 2560, 1100, 3000, 1024]`.

- сверхширокие макеты: строго больше 1920 px;
- узкие макеты: не более 1200 px;
- если максимальная ширина больше 2560 px, выводится предупреждение «Такой макет лучше разбить на несколько экранов».

## Структура

- `index.html` — разметка страницы
- `style.css` — оформление
- `script.js` — логика

## Что реализовано

- `"use strict"`, `let` и `const`, массивы
- Функции: `findMax`, `filterBy`, `sum`, `analyze`
- Циклы `for` и `for...of`, условия `if`
- Ввод и вывод: `prompt` (имя), `alert` (итог), `console.log` (подробный отчёт)
- Работа с DOM: вывод данных и результатов на страницу, обработчики `click`
- Кнопка «Изменить данные» с проверкой ввода (5–7 корректных чисел)

## Результат для исходных данных

| Показатель | Значение |
|---|---|
| Средняя ширина | 1814 px |
| Сверхширокие (> 1920 px) | 2 (2560 и 3000) |
| Узкие (≤ 1200 px) | 2 (1100 и 1024) |
| Доля узких | 33.3 % |
| Максимум | 3000 px (выводится предупреждение) |
